# Archived: LifeRise Lifestyle Coaching site

This folder contains the previous liferise.cc website — a lifestyle coaching
service with a client portal, resource library, and Cloudflare Worker backend.

It was retired and moved here (not deleted) on 2026-08-11 when liferise.cc was
repositioned as the corporate site for LifeRise Unlimited Corporation, the
holding company that also operates Shedlr.

Nothing in this folder is referenced by the active site. It's kept for
reference and in case any of it needs to be revived or repurposed later.
